## Evidence Delivery Format
All evidence must be delivered in two formats: screenshots and supporting text descriptions. Evidence should clearly demonstrate completion of each remediation step and should not expose any sensitive information (credentials, tokens, API keys, etc.).

| Issue Type                    | Reference evidence required                                                                                                                                                       |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Credential Rotation           | - Screenshot of rotated credential in system (username/ID visible, values redacted) <br>- Timestamp included<br>- Text confirmation of rotation method (e.g. command line output) |
| Access Control Implementation | - Screenshot of new control/rule/policy in system <br>- Configuration details or rule parameters <br>- Text summary of what was implemented                                       |
| Secret Detection Tool         | - Screenshot of tool enabled/active in repository or system <br>- Configuration settings visible or copied as text<br>- Test verification (e.g., blocked commit attempt)          |
| Documentation Update          | - Link to updated policy or procedure document <br>- Version control history showing change <br>- Text summary of changes made                                                    |

Deliver evidence (grouped where feasible) to ciso@klarrio.com
